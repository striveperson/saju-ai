# saju-ai

생년월일시로 사주를 계산해 보여주고, 그 판정이 무엇을 뜻하는지 AI 가 풀어 설명하는 서비스.

계산과 판정은 코드가 결정론적으로 한다. LLM 은 그 결과의 의미만 문장으로 풀어쓴다.

현재 상태는 설계 문서만 있고 코드는 없다.
