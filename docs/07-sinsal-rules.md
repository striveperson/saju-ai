# 07. 신살(神殺)과 길성

> 신살 판정 규칙의 단일 진실 공급원(SSOT)이다.
> [05-saju-domain-rules.md](05-saju-domain-rules.md) 와 같은 규율을 따른다.
> 코드와 이 문서가 어긋나면 코드가 틀린 것으로 간주한다.

05 에서 떼어 낸 이유는 신살이 만세력 파이프라인 밖이기 때문이다.
05 는 입력 시각에서 팔자와 운으로 가는 한 줄기라 장 사이 대조가 잦지만,
신살은 완성된 팔자 여덟 글자를 받아 목록을 낼 뿐이라 05 의 어느 장도 참조하지 않는다.

신살은 사주 영역 중 유파 편차가 가장 크고 전 유파가 합의한 표준 목록이 존재하지 않는다.
따라서 무엇을 채택하는지를 먼저 정하고, 채택한 것만 판정표를 여기에 고정한다.

17종을 전부 구현했다. 판정은 `apps/web/src/lib/saju/sinsal.ts` 에 있고
판정표는 `tables.ts` 의 신살 섹션에 있다.

코드와 이 문서가 어긋나면 코드가 틀린 것이다. 판정표는 2장에서 5장까지의 표를
한 줄씩 옮겨 `tables.test.ts` 가 대조하고, 판정 규칙은 `sinsal.test.ts` 가 검사한다.

## 1. 채택 등급

| 등급 | 정의                                                                   | 취급                                  |
| ---- | ---------------------------------------------------------------------- | ------------------------------------- |
| A    | 고전 문헌에 판정표가 실려 있고 문헌 간 표가 일치                       | 채택                                  |
| B    | 근거는 있으나 판정 기준(기준 간지, 포함 범위)이 유파별로 갈림          | 채택하되 따르는 유파를 이 문서에 명시 |
| C    | 고전 근거가 희박하고 자료마다 판정표가 다름 (한국 현대 실무 유래 계통) | 미채택                                |

C 를 미채택하는 이유는, 개수가 적어 보이는 것보다 근거를 댈 수 없는 판정이 섞이는 쪽이
결과 전체의 신뢰도를 더 떨어뜨리기 때문이다.
타 서비스에 있다는 사실은 채택 근거가 되지 않는다.

C 를 나중에 채택하려면 아래 세 조건을 모두 만족해야 한다.

1. 판정표의 출처를 문헌 단위로 특정한다.
2. 유파차가 있으면 어느 쪽을 따르는지와 그 이유를 이 문서에 기록한다.
3. 화면에서 A·B 등급과 구분해 표시한다.

## 2. 채택된 신살: 일간 기준

일간을 기준으로 삼고 네 지지(년월일시) 전부에서 찾는다. 맞는 자리마다 판정이 붙는다.

| 신살     | 판정                                                                      | 분류 | 등급 |
| -------- | ------------------------------------------------------------------------- | ---- | ---- |
| 천을귀인 | 갑무경→축미 / 을기→자신 / 병정→해유 / 신→인오 / 임계→묘사                 | 길성 | A    |
| 문창귀인 | 갑사 을오 병신 정유 무신 기유 경해 신자 임인 계묘                         | 길성 | A    |
| 정록     | 건록이라고도 한다. 갑인 을묘 병사 정오 무사 기오 경신 신유 임해 계자      | 길성 | A    |
| 학당귀인 | 일간의 장생지. 갑해 을오 병인 정유 무인 기유 경사 신자 임신 계묘          | 길성 | A    |
| 관귀학관 | 일간 정관 오행의 장생지. 갑을→사 병정→신 무기→해 경신임계→인              | 길성 | A    |
| 태극귀인 | 갑을→자오 / 병정→묘유 / 무기→진술축미 / 경신→인해 / 임계→사신             | 길성 | B    |
| 금여성   | 건록의 2번째 다음 지지. 갑진 을사 병미 정신 무미 기신 경술 신해 임축 계인 | 길성 | A    |
| 양인     | 양간의 제왕지. 갑묘 병오 무오 경유 임자                                   | 흉살 | B    |

양인의 유파 선택: 양간 5개만 채택한다.
음간 양인(을진, 정미, 기미, 신술, 계축)은 문헌마다 위치가 갈리고 아예 인정하지 않는 유파도 있어 제외한다.

태극귀인의 유파 선택: 일간 기준을 채택한다.
년간 기준으로 보는 유파가 있으나, 이 앱의 다른 귀인류(천을, 문창, 학당, 관귀학관)가 모두 일간 기준이라
기준을 일치시킨다.

금여성은 일간 건록지에서 2칸 뒤 지지라 `JEONGNOK` 테이블에서 기계적으로 유도된다.
별도 테이블로 둔 것은 가독성 때문이며 두 표는 항상 이 관계를 만족해야 한다.

## 3. 채택된 신살: 년지 기준

년지가 속한 방위 삼회 그룹으로 판정한다. 등급은 A 이고 분류는 둘 다 흉살이다.
기준은 년지 하나이고, 찾는 것은 네 지지 전부다. 년지 자신도 판정 대상에서 빼지 않는다.

방위 그룹은 해자축, 인묘진, 사오미, 신유술 순으로 돈다. 겨울에서 봄, 여름, 가을이고
지지 순환을 해부터 세 칸씩 끊은 것과 같다. 11장이 말하는 다음 그룹과 이전 그룹이 이 순서다.

| 년지 그룹 | 고신살 | 과숙살 |
| --------- | ------ | ------ |
| 해자축    | 인     | 술     |
| 인묘진    | 사     | 축     |
| 사오미    | 신     | 진     |
| 신유술    | 해     | 미     |

## 4. 채택된 신살: 주(柱) 간지 기준

한 기둥의 천간과 지지 조합이 목록과 일치하면 그 기둥의 천간과 지지 양쪽에 붙는다.
지지 단독 판정과 달리 `hits` 가 stem 과 branch 두 개로 나온다.

| 신살     | 판정 간지                          | 분류 | 등급 |
| -------- | ---------------------------------- | ---- | ---- |
| 백호대살 | 갑진 을미 병술 정축 무진 임술 계축 | 흉살 | B    |
| 괴강살   | 경진 경술 임진 무술                | 중립 | B    |

적용 범위는 년월일시 네 기둥 전부다. 일주만 보는 유파가 있으나 그 경우 월주 백호가 누락된다.

백호대살의 등급 근거: 판정 간지 7개는 자료 간 이견이 없으나
고전 자평서 수록 여부를 확정하지 못해 A 가 아닌 B 로 둔다. 이 사실을 알고 채택한 것이다.

괴강살의 유파 선택: 협의 4간지만 채택한다. 임술과 무진을 더해 6간지로 보는 유파는 제외한다.

어느 넷인지가 자료마다 갈려서 확인한 것을 적어 둔다(2026-08-15 조사).
넷을 고르는 방식이 둘이고, 갈리는 자리는 임술과 무술 중 어느 쪽을 넣는가다.
우리가 택한 무술 쪽은 연해자평과 삼명통회의 조합으로 소개되는 것이고,
그 계열은 임술을 괴강이 아니라 백호로 본다. 우리 백호대살 목록에 임술이 있는 것과 맞는다.
임술을 넣고 무술을 준괴강으로 미는 자료도 있어 이 선택이 유일한 답은 아니다.

무진 배제는 양쪽 자료가 함께 뒷받침한다. 출처가 불분명하다고 하거나 백호로 분류한다.
우리 백호대살 목록에 무진이 있다.

확인한 것이 2차 자료라 원전을 직접 대조하지는 못했다. 백호대살을 A 가 아닌 B 로 둔 것과
같은 사정이고, 괴강살도 그래서 B 다.

## 5. 채택된 신살: 삼합 기준

기준 지지가 속한 삼합 그룹에 따라 판정 지지가 정해진다.
찾는 것은 네 지지 전부이고, 기준으로 삼은 지지 자신도 판정 대상에서 빼지 않는다.

기준 지지가 자기 자신에 걸리는 것은 화개살뿐이다. 아래 표에서 화개 열만 그룹의
셋째 글자, 곧 그룹 안에 있는 글자를 가리키기 때문이다. 진년생은 신자진 그룹이라
화개가 진이고 년지 자신이 판정 자리가 된다. 년지를 스캔에서 빼면 이 판정이 사라진다.

| 삼합 그룹 | 도화살 | 역마살 | 화개살 | 겁살 | 망신살 |
| --------- | ------ | ------ | ------ | ---- | ------ |
| 신자진    | 유     | 인     | 진     | 사   | 해     |
| 인오술    | 묘     | 신     | 술     | 해   | 사     |
| 사유축    | 오     | 해     | 축     | 인   | 신     |
| 해묘미    | 자     | 사     | 미     | 신   | 인     |

분류는 도화살, 겁살, 망신살이 흉살이고 역마살과 화개살이 중립이다.

등급은 다섯 다 B 다. 삼합 그룹에서 지지를 잡는 표 자체는 자료 간 이견이 없지만,
기준 지지를 어디까지 볼 것인가가 유파별로 갈린다. 1장의 B 정의가 말하는
"판정 기준(기준 간지, 포함 범위)이 유파별로 갈림" 이 정확히 이 자리다.
따르는 유파는 아래에 밝히고, 기각한 쪽은 8장에 적었다.

기준 지지의 범위: 년지를 기본으로 하고, 일지가 년지와 다른 삼합 그룹일 때만 일지 기준을 병행한다.
같은 그룹이면 판정 결과가 동일하므로 중복 판정하지 않는다.
두 기준은 `basis` 필드(`삼합(년지)` 와 `삼합(일지)`)로 구분한다.

년지는 고전의 원칙 기준이고 일지 병행은 현대 실무에서 널리 쓰인다.
월지나 시지를 기준으로 삼는 방식은 문헌 근거를 확인하지 못해 채택하지 않는다. 경위는 8장에 있다.

## 6. 판정 결과의 구조

판정 결과는 `{ name, category, basis, hits }` 형태다.
`hits` 는 신살이 붙은 지점을 `{ pillar, position, char }` 로 가리킨다.

`name` 은 10장 목록의 표기를 정본으로 쓴다. 본문이 판정 근거를 설명하며 다른 이름을 쓰는 곳이
있으나(정록의 건록, 양인의 제왕지) 출력에 나가는 것은 10장 쪽이다.

`category` 는 길성, 흉살, 중립 셋이다.

`basis` 는 판정 기준을 가리키고 다섯이다. 일간, 년지, 주 간지, 삼합(년지), 삼합(일지).
앞의 셋은 2장, 3장, 4장에 대응하고 뒤의 둘은 5장이 갈라 둔 것이다.

`grade` 로 1장의 채택 등급을 함께 낸다. 네 필드에 더하는 다섯째다.
B 등급 넷(태극귀인, 양인, 백호대살, 괴강살)과 삼합 다섯은 유파 선택이 들어간 판정이고,
1장의 C 승격 조건 셋째가 화면에서 A 와 B 를 구분해 표시하라고 요구한다.
결과만 받는 화면이 그것을 하려면 등급이 결과 안에 있어야 한다.

`pillar` 는 년월일시 네 자리, `position` 은 천간과 지지 둘이다.
`position` 이 천간이 되는 것은 4장의 주 간지 기준뿐이고 나머지는 전부 지지다.

붙는 자리가 하나도 없는 신살은 항목을 만들지 않는다. `hits` 가 빈 배열인 결과를 내지 않는다.
17종이 항상 나오는 것이 아니라 걸린 것만 나온다.

같은 신살이 서로 다른 `basis` 로 중복 판정될 수 있다.
계산 코어는 중복을 그대로 두고 표시 단계에서 이름 단위로 접는다.

출력 순서를 고정한다. 목록은 10장 표의 순서를 따르고, 같은 신살이 둘로 나오면
`삼합(년지)` 가 `삼합(일지)` 보다 앞이며, `hits` 안은 년월일시 순이고
한 기둥 안에서는 천간이 지지보다 앞이다.

순서를 정하는 이유는 해석 캐시다. 루트 CLAUDE.md 가 캐시 키를 팔자와 판정 결과의 해시로
정해 두었으므로, 같은 팔자가 실행마다 다른 순서를 내면 키가 갈라져 캐시가 어긋난다.

## 7. 기각 기록: 현침살 제거

현침살(천간 갑과 신, 지지 묘·오·미·신)은 글자의 획 모양에서 유래한 계통이라
고전 판정 근거가 약해 1장 기준으로는 C 에 해당한다.
채택 기준을 만들기 전에 구현된 항목이었으나 기준을 소급 적용해 제거했다.

신규 신살을 추가할 때 현침살을 선례로 삼지 않는다.
재도입하려면 1장의 C 승격 3조건을 만족해야 한다.

## 8. 기각 기록: 삼합 신살의 기준 지지 전 범위 확장

타 서비스(포스텔러) 결과에서는 삼합 신살이 네 지지 전부를 각각 기준으로 삼은 것처럼 나타난다.
이 앱에는 도입하지 않는다.

근거가 명식 1개를 역산한 추정뿐이고, 그 명식에는 인신사해가 하나도 없어
역마, 겁살, 망신으로 반증할 기회조차 없었다.
타 서비스의 출력은 1장이 말하는 채택 근거가 아니다.
천문성과 귀문관살을 미채택한 것과 같은 기준을 여기에도 적용한다.

재검토 조건은 월지나 시지 기준을 지지하는 문헌 근거를 확보한 경우에 한한다.
타 서비스와의 출력 차이는 재검토 사유가 아니다.

## 9. 미채택 목록

C 등급이라 채택하지 않은 것: 천문성, 귀문관살, 황은대사, 급각살, 단교관살.

A·B 등급이지만 아직 미구현이라 추가 후보인 것: 천덕귀인, 월덕귀인(월지 기준, 삼명통회 계열).

## 11. 필수 경계 테스트 목록

구현을 변경할 때 아래를 반드시 통과해야 한다. 판정표 자체는 2장에서 5장까지의 표를
한 줄씩 그대로 옮겨 검사하고, 여기 적는 것은 표만으로는 드러나지 않는 것들이다.

- 금여성이 정록에서 두 칸 뒤다. 열 간 전부에서 성립하는지(2장 끝 문단이 요구한다)
- 양인이 양간 다섯에만 있고 음간에는 없다
- 태극귀인은 무기만 지지 넷이고 나머지 여덟 간은 둘이다
- 천을귀인도 일간마다 지지 둘이다
- 백호대살과 괴강살이 년월일시 네 기둥 전부에서 잡힌다. 월주 백호가 누락되지 않는지
- 백호대살과 괴강살은 `hits` 가 천간과 지지 둘로 나온다. 나머지 열다섯은 지지 하나다
- 년지와 일지가 같은 삼합 그룹이면 삼합 신살이 중복 판정되지 않는다
- 년지와 일지가 다른 삼합 그룹이면 `basis` 가 둘로 나뉜다
- 네 지지에 같은 글자가 둘 이상이면 `hits` 도 그 수만큼 나온다
- 붙는 자리가 없는 신살은 결과에 나오지 않는다
- 채택 목록이 17종이고 10장 표와 어긋나지 않는다
- 출력 순서가 결정적이다. 같은 팔자를 두 번 계산하면 순서까지 같다

판정표를 옮겨 적다 틀린 것은 전사 테스트로 잡히지 않는다. 코드와 테스트에 같은 값을
두 번 적는 형태라 같은 실수를 두 번 하면 통과한다. 아래 관계가 그 방어선이다.

- 금여성이 정록에서 두 칸 뒤다
- 고신살은 년지 그룹의 다음 방위 그룹 첫 글자이고, 과숙살은 이전 그룹 끝 글자다
- 삼합 다섯 열이 각각 단사다. 한 열 안에서 네 그룹의 값이 서로 다르다
- 화개살은 그룹의 셋째 글자다
- 겁살과 망신살은 값이 서로 교차한다. 신자진의 겁살이 사이고 인오술의 망신이 사다.
  옮겨 적을 때 가장 틀리기 쉬운 자리다
- 괴강살 목록에 임술과 무진이 없다. 둘 다 백호대살에는 있어 회귀가 나기 쉽다
- 백호대살과 괴강살의 판정 간지가 전부 60갑자에 실재한다
