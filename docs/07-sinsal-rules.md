# 07. 신살(神殺)과 길성

> 신살 판정 규칙의 단일 진실 공급원(SSOT)이다.
> [05-saju-domain-rules.md](05-saju-domain-rules.md) 와 같은 규율을 따른다.
> 코드와 이 문서가 어긋나면 코드가 틀린 것으로 간주한다.

05 에서 떼어 낸 이유는 신살이 만세력 파이프라인 밖이기 때문이다.
05 는 입력 시각에서 팔자와 운으로 가는 한 줄기라 장 사이 대조가 잦지만,
신살은 완성된 팔자 여덟 글자를 받아 목록을 낼 뿐이라 05 의 어느 장도 참조하지 않는다.

신살은 사주 영역 중 유파 편차가 가장 크고 전 유파가 합의한 표준 목록이 존재하지 않는다.
따라서 무엇을 채택하는지를 먼저 정하고, 채택한 것만 판정표를 여기에 고정한다.

아직 구현하지 않았다. 이 문서는 만들 때 따를 스펙이다.
판정은 `apps/web/src/lib/saju/sinsal.ts` 에, 판정표는 `tables.ts` 의 신살 섹션에 둔다.

## 1. 채택 등급

| 등급 | 정의                                                                   | 취급                                  |
| ---- | ---------------------------------------------------------------------- | ------------------------------------- |
| A    | 고전 문헌에 판정표가 실려 있고 문헌 간 표가 일치                       | 채택                                  |
| B    | 근거는 있으나 판정 기준(기준 간지, 포함 범위)이 유파별로 갈림          | 채택하되 따르는 유파를 이 문서에 명시 |
| C    | 고전 근거가 희박하고 자료마다 판정표가 다름 (한국 현대 실무 유래 계통) | 미채택                                |

C 를 미채택하는 이유는, 개수가 적어 보이는 것보다 근거를 댈 수 없는 판정이 섞이는 쪽이
결과 전체의 신뢰도를 더 떨어뜨리기 때문이다.
타 서비스에 있다는 사실은 채택 근거가 되지 않는다.

C 를 나중에 채택하려면 아래 세 조건을 모두 만족해야 한다.

1. 판정표의 출처를 문헌 단위로 특정한다.
2. 유파차가 있으면 어느 쪽을 따르는지와 그 이유를 이 문서에 기록한다.
3. 화면에서 A·B 등급과 구분해 표시한다.

## 2. 채택된 신살: 일간 기준

| 신살       | 판정                                                                      | 분류 | 등급 |
| ---------- | ------------------------------------------------------------------------- | ---- | ---- |
| 천을귀인   | 갑무경→축미 / 을기→자신 / 병정→해유 / 신→인오 / 임계→묘사                 | 길성 | A    |
| 문창귀인   | 갑사 을오 병신 정유 무신 기유 경해 신자 임인 계묘                         | 길성 | A    |
| 정록(건록) | 갑인 을묘 병사 정오 무사 기오 경신 신유 임해 계자                         | 길성 | A    |
| 학당귀인   | 일간의 장생지. 갑해 을오 병인 정유 무인 기유 경사 신자 임신 계묘          | 길성 | A    |
| 관귀학관   | 일간 정관 오행의 장생지. 갑을→사 병정→신 무기→해 경신임계→인              | 길성 | A    |
| 태극귀인   | 갑을→자오 / 병정→묘유 / 무기→진술축미 / 경신→인해 / 임계→사신             | 길성 | B    |
| 금여성     | 건록의 2번째 다음 지지. 갑진 을사 병미 정신 무미 기신 경술 신해 임축 계인 | 길성 | A    |
| 양인       | 양간의 제왕지. 갑묘 병오 무오 경유 임자                                   | 흉살 | B    |

양인의 유파 선택: 양간 5개만 채택한다.
음간 양인(을진, 정미, 기미, 신술, 계축)은 문헌마다 위치가 갈리고 아예 인정하지 않는 유파도 있어 제외한다.

태극귀인의 유파 선택: 일간 기준을 채택한다.
년간 기준으로 보는 유파가 있으나, 이 앱의 다른 귀인류(천을, 문창, 학당, 관귀학관)가 모두 일간 기준이라
기준을 일치시킨다.

금여성은 일간 건록지에서 2칸 뒤 지지라 `JEONGNOK` 테이블에서 기계적으로 유도된다.
별도 테이블로 둔 것은 가독성 때문이며 두 표는 항상 이 관계를 만족해야 한다.

## 3. 채택된 신살: 년지 기준

년지가 속한 방위 삼회 그룹으로 판정한다. 등급은 A 이고 분류는 둘 다 흉살이다.

| 년지 그룹 | 고신살 | 과숙살 |
| --------- | ------ | ------ |
| 해자축    | 인     | 술     |
| 인묘진    | 사     | 축     |
| 사오미    | 신     | 진     |
| 신유술    | 해     | 미     |

## 4. 채택된 신살: 주(柱) 간지 기준

한 기둥의 천간과 지지 조합이 목록과 일치하면 그 기둥의 천간과 지지 양쪽에 붙는다.
지지 단독 판정과 달리 `hits` 가 stem 과 branch 두 개로 나온다.

| 신살     | 판정 간지                          | 분류 | 등급 |
| -------- | ---------------------------------- | ---- | ---- |
| 백호대살 | 갑진 을미 병술 정축 무진 임술 계축 | 흉살 | B    |
| 괴강살   | 경진 경술 임진 무술                | 중립 | B    |

적용 범위는 년월일시 네 기둥 전부다. 일주만 보는 유파가 있으나 그 경우 월주 백호가 누락된다.

백호대살의 등급 근거: 판정 간지 7개는 자료 간 이견이 없으나
고전 자평서 수록 여부를 확정하지 못해 A 가 아닌 B 로 둔다. 이 사실을 알고 채택한 것이다.

괴강살의 유파 선택: 협의 4간지만 채택한다. 임술과 무진을 더해 6간지로 보는 유파는 제외한다.

## 5. 채택된 신살: 삼합 기준

기준 지지가 속한 삼합 그룹에 따라 판정 지지가 정해진다.

| 삼합 그룹 | 도화 | 역마 | 화개 | 겁살 | 망신 |
| --------- | ---- | ---- | ---- | ---- | ---- |
| 신자진    | 유   | 인   | 진   | 사   | 해   |
| 인오술    | 묘   | 신   | 술   | 해   | 사   |
| 사유축    | 오   | 해   | 축   | 인   | 신   |
| 해묘미    | 자   | 사   | 미   | 신   | 인   |

분류는 도화, 겁살, 망신이 흉살이고 역마와 화개가 중립이다.

기준 지지의 범위: 년지를 기본으로 하고, 일지가 년지와 다른 삼합 그룹일 때만 일지 기준을 병행한다.
같은 그룹이면 판정 결과가 동일하므로 중복 판정하지 않는다.
두 기준은 `basis` 필드(`삼합(년지)` 와 `삼합(일지)`)로 구분한다.

년지는 고전의 원칙 기준이고 일지 병행은 현대 실무에서 널리 쓰인다.
월지나 시지를 기준으로 삼는 방식은 문헌 근거를 확인하지 못해 채택하지 않는다. 경위는 8장에 있다.

## 6. 판정 결과의 구조

판정 결과는 `{ name, category, basis, hits }` 형태다.
`hits` 는 신살이 붙은 지점을 `{ pillar, position, char }` 로 가리킨다.

같은 신살이 서로 다른 `basis` 로 중복 판정될 수 있다.
계산 코어는 중복을 그대로 두고 표시 단계에서 이름 단위로 접는다.

## 7. 기각 기록: 현침살 제거

현침살(천간 갑과 신, 지지 묘·오·미·신)은 글자의 획 모양에서 유래한 계통이라
고전 판정 근거가 약해 1장 기준으로는 C 에 해당한다.
채택 기준을 만들기 전에 구현된 항목이었으나 기준을 소급 적용해 제거했다.

신규 신살을 추가할 때 현침살을 선례로 삼지 않는다.
재도입하려면 1장의 C 승격 3조건을 만족해야 한다.

## 8. 기각 기록: 삼합 신살의 기준 지지 전 범위 확장

타 서비스(포스텔러) 결과에서는 삼합 신살이 네 지지 전부를 각각 기준으로 삼은 것처럼 나타난다.
이 앱에는 도입하지 않는다.

근거가 명식 1개를 역산한 추정뿐이고, 그 명식에는 인신사해가 하나도 없어
역마, 겁살, 망신으로 반증할 기회조차 없었다.
타 서비스의 출력은 1장이 말하는 채택 근거가 아니다.
천문성과 귀문관살을 미채택한 것과 같은 기준을 여기에도 적용한다.

재검토 조건은 월지나 시지 기준을 지지하는 문헌 근거를 확보한 경우에 한한다.
타 서비스와의 출력 차이는 재검토 사유가 아니다.

## 9. 미채택 목록

C 등급이라 채택하지 않은 것: 천문성, 귀문관살, 황은대사, 급각살, 단교관살.

A·B 등급이지만 아직 미구현이라 추가 후보인 것: 천덕귀인, 월덕귀인(월지 기준, 삼명통회 계열).
