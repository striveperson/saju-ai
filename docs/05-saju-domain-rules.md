# 05. 사주 계산 도메인 규칙

> 사주 계산 로직을 구현하고 검증할 때 참조하는 단일 진실 공급원(SSOT)이다.
> 코드와 이 문서가 어긋나면 코드가 틀린 것으로 간주한다.
> 이 문서가 틀렸다면 근거와 함께 문서를 먼저 고치고 그 다음 코드를 고친다.

구현 위치는 `apps/web/src/lib/saju/` 이며 외부 의존이 없는 순수 함수로 작성한다
([ADR 0001](adr/0001-monorepo-pnpm-workspaces.md), [ADR 0013](adr/0013-saju-engine-purity-enforcement.md)).
검증 케이스는 `apps/web/src/lib/saju/fixtures/saju-verification-cases.json` 에 두고
`verified: true` 케이스를 회귀 테스트가 실행한다.

## 1. 60갑자 기본

- 천간(天干) 10개: 갑(甲) 을(乙) 병(丙) 정(丁) 무(戊) 기(己) 경(庚) 신(辛) 임(壬) 계(癸)
- 지지(地支) 12개: 자(子) 축(丑) 인(寅) 묘(卯) 진(辰) 사(巳) 오(午) 미(未) 신(申) 유(酉) 술(戌) 해(亥)
- 60갑자 인덱스: 갑자가 0, 을축이 1, 계해가 59 인 순환.
- 천간 음양: 갑·병·무·경·임이 양(陽), 을·정·기·신·계가 음(陰).
- 천간 오행: 갑을 목, 병정 화, 무기 토, 경신 금, 임계 수.
- 지지 오행: 인묘 목, 사오 화, 진술축미 토, 신유 금, 해자 수.

## 2. 년주(年柱)

년주 경계는 입춘 절입 시각이며 분 단위로 판정한다. 양력 1월 1일도 아니고 음력 설날도 아니다.
입춘 절입 시각 이전 출생이면 전년도 년주를 쓴다.

## 3. 월주(月柱)

월 경계를 만드는 것은 12절(節)이다. 12중기(中氣: 우수, 춘분 등)는 월 경계와 무관하다.

| 월지(月支) | 절기 시작 | 대략 양력 |
| ---------- | --------- | --------- |
| 인(寅) | 입춘(立春) | 2/4경 |
| 묘(卯) | 경칩(驚蟄) | 3/6경 |
| 진(辰) | 청명(淸明) | 4/5경 |
| 사(巳) | 입하(立夏) | 5/6경 |
| 오(午) | 망종(芒種) | 6/6경 |
| 미(未) | 소서(小暑) | 7/7경 |
| 신(申) | 입추(立秋) | 8/8경 |
| 유(酉) | 백로(白露) | 9/8경 |
| 술(戌) | 한로(寒露) | 10/8경 |
| 해(亥) | 입동(立冬) | 11/7경 |
| 자(子) | 대설(大雪) | 12/7경 |
| 축(丑) | 소한(小寒) | 1/6경 |

"대략 양력"은 참고용이다. 실제 판정은 반드시 KASI 절입 시각 데이터로 한다.

### 3.1 월두법(月頭法, 오호둔 五虎遁)

년간에서 인월(정월)의 월간을 정한다.

| 년간 | 인월(정월) 월주 |
| ---- | --------------- |
| 갑(甲)·기(己) | 병인(丙寅) |
| 을(乙)·경(庚) | 무인(戊寅) |
| 병(丙)·신(辛) | 경인(庚寅) |
| 정(丁)·임(壬) | 임인(壬寅) |
| 무(戊)·계(癸) | 갑인(甲寅) |

이후 월은 60갑자 순서로 진행한다.

## 4. 일주(日柱)

기준 앵커 날짜로부터 `(일수 차이) mod 60` 으로 계산한다.

앵커 값을 이 문서에 하드코딩하지 않는다.
`fixtures/saju-verification-cases.json` 에서 공인 만세력 대조로 `verified: true` 처리된
케이스 3개 이상으로 확정한다.

자시 경계(23시)의 날짜 귀속은 6장 야자시 정책을 따른다.

## 5. 시주(時柱)

### 5.1 시지(時支) 구간

진태양시 보정을 적용한 뒤의 시각을 기준으로 판정한다.

자(23-01), 축(01-03), 인(03-05), 묘(05-07), 진(07-09), 사(09-11),
오(11-13), 미(13-15), 신(15-17), 유(17-19), 술(19-21), 해(21-23)

### 5.2 시두법(時頭法, 오서둔 五鼠遁)

일간에서 자시의 시간(時干)을 정한다.

| 일간 | 자시(子時) 시주 |
| ---- | --------------- |
| 갑(甲)·기(己) | 갑자(甲子) |
| 을(乙)·경(庚) | 병자(丙子) |
| 병(丙)·신(辛) | 무자(戊子) |
| 정(丁)·임(壬) | 경자(庚子) |
| 무(戊)·계(癸) | 임자(壬子) |

## 6. 야자시(夜子時)와 조자시(朝子時)

23:00~24:00 출생의 일주 귀속은 유파가 갈린다.

- 정자시설(正子時說): 23시부터 다음날로 본다. 일주가 다음날 간지가 된다.
- 야자시설(夜子時說): 자정까지는 당일 일주를 유지하고 시주만 자시로 잡는다.
  00:00~01:00 은 조자시(朝子時)로 그날 일주다.

단일 정답을 강요하지 않고 설정 옵션으로 제공한다.
기본값은 제품 결정 사항이며, 어떤 값을 택하든 결과 화면에 적용된 방식을 명시한다.

코드 대응(`SajuOptions.ziPolicy`): 야자시설이 `sameDay`, 정자시설이 `nextDay` 다.
검증 케이스 JSON 의 `night_zi_policy` 는 `ye` 가 `sameDay`, `zheng` 이 `nextDay` 에 대응한다.

## 7. 시간 보정 파이프라인

입력 시각에 아래 순서로 보정을 적용한 뒤 시지를 판정한다.

1. 표준시 이력 정규화
2. 서머타임 해제
3. 진태양시 보정 (옵션)

### 7.1 한국 표준시 이력

| 기간 | 표준시 |
| ---- | ------ |
| 1908-04-01 ~ 1911-12-31 | UTC+8:30 |
| 1912-01-01 ~ 1954-03-20 | UTC+9:00 |
| 1954-03-21 ~ 1961-08-09 | UTC+8:30 |
| 1961-08-10 ~ 현재 | UTC+9:00 |

구현 노트: 표준시를 UTC 오프셋 이동으로 정규화하는 대신,
해당 날짜의 표준 자오선 이력(UTC+8:30 시기가 127.5도, 그 외가 135도)을
진태양시 보정식에 반영하는 방식으로 같은 효과를 낼 수 있다.
두 방식은 시지 판정에 대해 동등하다.

### 7.2 서머타임(일광절약시간)

1948~1951년, 1955~1960년, 1987~1988년에 시행되었다.
매년 대략 5월부터 9월 구간이지만 연도별 정확한 시작일과 종료일이 다르다.

연도별 구간은 tz database `Asia/Seoul` 기준으로 처리한다.
tz database 가 위 표준시 이력과 서머타임을 모두 포함한다.

주의: 병원 출생 기록이 서머타임 적용 시각인지 알 수 없는 경우가 많다.
출생 기록 시각이 서머타임을 반영한 시각인지 사용자에게 확인하는 화면이 이상적이다.

### 7.3 진태양시 보정 (옵션)

- 평균태양시 보정은 `(출생지 경도 - 당시 표준 자오선) × 4분/도` 다.
  자오선 135도 기준으로 서울(126.98°E)은 약 -32분, 부산(129.08°E)은 약 -24분이다.
- 경도 입력이 원칙이다.
  경도를 모를 때만 -30분(서울 관례값)을 폴백으로 쓰되,
  표준 자오선이 127.5도이던 시기에는 0분으로 조정하고 폴백을 썼다는 사실을 화면에 명시한다.
  -30분 고정만 제공하고 경도 입력이 불가능한 구현은 오류로 본다.
- 균시차(均時差, equation of time, 연중 약 ±15분 변동) 반영은 추가 옵션이다(유파 선택).

## 8. 음력 입력 처리

- 사주 판정 자체는 절기(양력 태양 위치) 기준이므로 음력은 입력 편의 기능일 뿐이다.
- 음력에서 양력으로의 변환은 KASI 공식 데이터를 기준으로 한다.
  윤달(閏月) 여부 플래그를 입력받아야 한다.
  같은 "음력 4월 10일"이 평달과 윤달로 두 번 존재할 수 있다.
- 자체 음력 산출 알고리즘을 구현하지 않는다.
  한국 음력은 천문 계산과 관습 규칙이 섞여 있어 공식 데이터 대조 없이는 오차가 난다.

## 9. 대운(大運)

1. 방향: 년간이 양이고 남자이거나, 년간이 음이고 여자면 순행(順行)이다. 반대 조합이면 역행(逆行)이다.
2. 대운수(첫 대운 나이): 출생 시각부터 순행이면 다음 절입까지, 역행이면 직전 절입까지의 시간을 계산해
   3일을 1년으로 환산한다. 나머지 처리(1일이 4개월, 1시간이 약 5일)는 유파별로 다르므로 설정 옵션으로 둔다.
3. 대운 간지: 월주에서 시작해 순행이나 역행 방향으로 60갑자를 진행한다.
   통상 10년 단위로 8개에서 10개를 표시한다.
4. 나이 표기: 대운과 세운 나이는 만 나이로 표시한다.
   첫 대운 나이는 기운(起運)까지 경과한 만 연수(정밀 환산의 연 단위 몫)이고 이후 대운마다 10을 더한다.
   만세력 라이브러리가 세는나이를 반환하면 그대로 쓰지 않고 변환한다.
   화면에는 만 나이임을 병기한다.

## 11. 신강약(身强弱)과 억부용신(抑扶用神)

신강약 백분율과 용신 분기는 업계 표준이 없는 정량화 모델이므로 이 앱의 결정을 여기에 기록한다.
5단계 4요소 모델을 쓴다([ADR 0007](adr/0007-strength-five-grade-model.md)).

구현은 `apps/web/src/lib/saju/strength.ts` 이고 가중치와 임계값은 설정 상수로 노출한다.

### 11.1 입력

만세력 계산이 산출한 사주팔자(년월일시 각 천간과 지지)와 일간.
강약 판정은 만세력 계산과 분리된 순수 함수로 구현한다.

### 11.2 십성 관계 분류

일간 오행을 기준으로 다섯으로 나눈다.

| 분류 | 관계 |
| ---- | ---- |
| 비겁 | 일간과 같은 오행 |
| 인성 | 일간을 생하는 오행 |
| 식상 | 일간이 생하는 오행 |
| 재성 | 일간이 극하는 오행 |
| 관성 | 일간을 극하는 오행 |

지원 세력은 비겁과 인성의 합이다.

### 11.3 판정 요소 네 가지

| 요소 | 정의 |
| ---- | ---- |
| 득령(得令) | 월지 본기 오행이 지원 세력 |
| 득지(得地) | 일지 본기 오행이 지원 세력 |
| 득시(得時) | 시지 본기 오행이 지원 세력 |
| 득세(得勢) | 일간을 제외한 7글자 중 지원 세력 글자가 4개 이상 |

유파 옵션: 득령·득지·득시를 비겁만으로 좁히는 유파가 있다.
`supportIncludesResource` 설정으로 제어하며 기본값은 true 다.

### 11.4 등급 산출

1. 네 요소가 모두 참이면 태강(太强)이다.
2. 네 요소가 모두 거짓이고 지원 글자 수(일간 제외)가 1개 이하면 태약(太弱)이다.
3. 그 외에는 가중 점수로 판정한다. `score = 득령×2.0 + 득지×1.0 + 득시×0.5 + 득세×1.5` 이고 만점은 5.0 이다.

| score | 등급 |
| ----- | ---- |
| 3.0 이상 | 신강(身强) |
| 1.5 이상 3.0 미만 | 중화(中和) |
| 1.5 미만 | 신약(身弱) |

가중치와 임계값은 전부 설정으로 노출한다.
기본값은 11.7 의 검증 케이스를 재현하도록 잡은 것이며 verified 케이스가 늘어나면 재보정한다.
월령 가중(득령 2.0)이 가장 크다는 원칙만 유지한다.

### 11.5 용신 분기

| 등급 | 1순위 | 2순위 | 비고 |
| ---- | ----- | ----- | ---- |
| 태강 | 식상(설기洩氣) | 재성 | 왕신충발(旺神沖發) 회피. 관성 극제는 후순위. 원국에 식상이 0퍼센트여도 결핍 보충 관점에서 선택한다 |
| 신강 | 관성(극제剋制) | 재성 | 관성이 지장간 포함 무근(無根)이고 식상이 유근이면 식상으로 대체하고 사유를 결과에 표기한다 |
| 중화 | 억부 불필요 | 없음 | `needsJohuReview` 플래그를 올려 조후나 병약 등 다른 용신법 검토로 넘긴다 |
| 신약 | 인성(생조生助) | 비겁 | |
| 태약 | 인성 | 비겁 | `considerJongGyeok` 플래그. 지원 세력이 사실상 없으면 종격(從格) 검토 |

통근(通根) 판정: 해당 오행이 네 지지의 지장간(여기, 중기, 본기 전부) 어디에든 존재하면 유근이다.

태강이면서 식상, 재성, 관성이 모두 부재하면 `considerJeonWangGyeok`(전왕격, 종왕격) 플래그를 올린다.

### 11.6 출력 형식

```ts
// apps/web/src/lib/saju/strength.ts
type StrengthResult = {
  grade: '태강' | '신강' | '중화' | '신약' | '태약'
  flags: { deukRyeong: boolean; deukJi: boolean; deukSi: boolean; deukSe: boolean }
  score: number
  supportRatio: number        // 일간 포함 8글자 균등(각 12.5%) 기준 지원 비율
  elementDistribution: Record<Element, { count: number; ratio: number }>
  yongshin: { element: Element; method: string; fallbackReason?: string }
  huisin: Element             // 희신(2순위)
  flags2: {
    needsJohuReview: boolean
    considerJongGyeok: boolean
    considerJeonWangGyeok: boolean
  }
}
```

화면 권장: 유파가 갈리는 지점이므로 "용신 금(설기) / 차선 목(극제)"처럼 병기하고 적용 방식을 명시한다.

### 11.7 검증 기준 케이스

1995-01-27 14:39 여, 서울. 갑술(甲戌)·정축(丁丑)·무오(戊午)·기미(己未), 일간 무토.

- 네 요소 전부 참(축토 득령, 오화 인성 득지, 미토 득시, 지원 6/7 득세)이므로 태강이다.

### 11.8 기각 기록: 8단계 방조비율 모델

8단계 기준으로 verified 케이스를 다시 확보한 경우에 한한다.

## 12. 신살(神殺)과 길성

신살은 사주 영역 중 유파 편차가 가장 크고 전 유파가 합의한 표준 목록이 존재하지 않는다.
따라서 무엇을 채택하는지를 먼저 정하고, 채택한 것만 판정표를 여기에 고정한다.

구현은 `apps/web/src/lib/saju/sinsal.ts`, 판정표는 `tables.ts` 의 신살 섹션이다.

### 12.1 채택 등급

| 등급 | 정의 | 취급 |
| ---- | ---- | ---- |
| A | 고전 문헌에 판정표가 실려 있고 문헌 간 표가 일치 | 채택 |
| B | 근거는 있으나 판정 기준(기준 간지, 포함 범위)이 유파별로 갈림 | 채택하되 따르는 유파를 이 문서에 명시 |
| C | 고전 근거가 희박하고 자료마다 판정표가 다름 (한국 현대 실무 유래 계통) | 미채택 |

C 를 미채택하는 이유는, 개수가 적어 보이는 것보다 근거를 댈 수 없는 판정이 섞이는 쪽이
결과 전체의 신뢰도를 더 떨어뜨리기 때문이다.
타 서비스에 있다는 사실은 채택 근거가 되지 않는다.

C 를 나중에 채택하려면 아래 세 조건을 모두 만족해야 한다.

1. 판정표의 출처를 문헌 단위로 특정한다.
2. 유파차가 있으면 어느 쪽을 따르는지와 그 이유를 이 문서에 기록한다.
3. 화면에서 A·B 등급과 구분해 표시한다.

### 12.2 채택된 신살: 일간 기준

| 신살 | 판정 | 분류 | 등급 |
| ---- | ---- | ---- | ---- |
| 천을귀인 | 갑무경→축미 / 을기→자신 / 병정→해유 / 신→인오 / 임계→묘사 | 길성 | A |
| 문창귀인 | 갑사 을오 병신 정유 무신 기유 경해 신자 임인 계묘 | 길성 | A |
| 정록(건록) | 갑인 을묘 병사 정오 무사 기오 경신 신유 임해 계자 | 길성 | A |
| 학당귀인 | 일간의 장생지. 갑해 을오 병인 정유 무인 기유 경사 신자 임신 계묘 | 길성 | A |
| 관귀학관 | 일간 정관 오행의 장생지. 갑을→사 병정→신 무기→해 경신임계→인 | 길성 | A |
| 태극귀인 | 갑을→자오 / 병정→묘유 / 무기→진술축미 / 경신→인해 / 임계→사신 | 길성 | B |
| 금여성 | 건록의 2번째 다음 지지. 갑진 을사 병미 정신 무미 기신 경술 신해 임축 계인 | 길성 | A |
| 양인 | 양간의 제왕지. 갑묘 병오 무오 경유 임자 | 흉살 | B |

양인의 유파 선택: 양간 5개만 채택한다.
음간 양인(을진, 정미, 기미, 신술, 계축)은 문헌마다 위치가 갈리고 아예 인정하지 않는 유파도 있어 제외한다.

태극귀인의 유파 선택: 일간 기준을 채택한다.
년간 기준으로 보는 유파가 있으나, 이 앱의 다른 귀인류(천을, 문창, 학당, 관귀학관)가 모두 일간 기준이라
기준을 일치시킨다.

금여성은 일간 건록지에서 2칸 뒤 지지라 `JEONGNOK` 테이블에서 기계적으로 유도된다.
별도 테이블로 둔 것은 가독성 때문이며 두 표는 항상 이 관계를 만족해야 한다.

### 12.3 채택된 신살: 년지 기준

년지가 속한 방위 삼회 그룹으로 판정한다. 등급은 A 이고 분류는 둘 다 흉살이다.

| 년지 그룹 | 고신살 | 과숙살 |
| --------- | ------ | ------ |
| 해자축 | 인 | 술 |
| 인묘진 | 사 | 축 |
| 사오미 | 신 | 진 |
| 신유술 | 해 | 미 |

### 12.4 채택된 신살: 주(柱) 간지 기준

한 기둥의 천간과 지지 조합이 목록과 일치하면 그 기둥의 천간과 지지 양쪽에 붙는다.
지지 단독 판정과 달리 `hits` 가 stem 과 branch 두 개로 나온다.

| 신살 | 판정 간지 | 분류 | 등급 |
| ---- | --------- | ---- | ---- |
| 백호대살 | 갑진 을미 병술 정축 무진 임술 계축 | 흉살 | B |
| 괴강살 | 경진 경술 임진 무술 | 중립 | B |

적용 범위는 년월일시 네 기둥 전부다. 일주만 보는 유파가 있으나 그 경우 월주 백호가 누락된다.

백호대살의 등급 근거: 판정 간지 7개는 자료 간 이견이 없으나
고전 자평서 수록 여부를 확정하지 못해 A 가 아닌 B 로 둔다. 이 사실을 알고 채택한 것이다.

괴강살의 유파 선택: 협의 4간지만 채택한다. 임술과 무진을 더해 6간지로 보는 유파는 제외한다.

### 12.5 채택된 신살: 삼합 기준

기준 지지가 속한 삼합 그룹에 따라 판정 지지가 정해진다.

| 삼합 그룹 | 도화 | 역마 | 화개 | 겁살 | 망신 |
| --------- | ---- | ---- | ---- | ---- | ---- |
| 신자진 | 유 | 인 | 진 | 사 | 해 |
| 인오술 | 묘 | 신 | 술 | 해 | 사 |
| 사유축 | 오 | 해 | 축 | 인 | 신 |
| 해묘미 | 자 | 사 | 미 | 신 | 인 |

분류는 도화, 겁살, 망신이 흉살이고 역마와 화개가 중립이다.

기준 지지의 범위: 년지를 기본으로 하고, 일지가 년지와 다른 삼합 그룹일 때만 일지 기준을 병행한다.
같은 그룹이면 판정 결과가 동일하므로 중복 판정하지 않는다.
두 기준은 `basis` 필드(`삼합(년지)` 와 `삼합(일지)`)로 구분한다.

년지는 고전의 원칙 기준이고 일지 병행은 현대 실무에서 널리 쓰인다.
월지나 시지를 기준으로 삼는 방식은 문헌 근거를 확인하지 못해 채택하지 않는다. 경위는 12.8 에 있다.

### 12.6 판정 결과의 구조

판정 결과는 `{ name, category, basis, hits }` 형태다.
`hits` 는 신살이 붙은 지점을 `{ pillar, position, char }` 로 가리킨다.

같은 신살이 서로 다른 `basis` 로 중복 판정될 수 있다.
계산 코어는 중복을 그대로 두고 표시 단계에서 이름 단위로 접는다.

### 12.7 기각 기록: 현침살 제거

현침살(천간 갑과 신, 지지 묘·오·미·신)은 글자의 획 모양에서 유래한 계통이라
고전 판정 근거가 약해 12.1 기준으로는 C 에 해당한다.
채택 기준을 만들기 전에 구현된 항목이었으나 기준을 소급 적용해 제거했다.

신규 신살을 추가할 때 현침살을 선례로 삼지 않는다.
재도입하려면 12.1 의 C 승격 3조건을 만족해야 한다.

### 12.8 기각 기록: 삼합 신살의 기준 지지 전 범위 확장

타 서비스(포스텔러) 결과에서는 삼합 신살이 네 지지 전부를 각각 기준으로 삼은 것처럼 나타난다.
이 앱에는 도입하지 않는다.

근거가 명식 1개를 역산한 추정뿐이고, 그 명식에는 인신사해가 하나도 없어
역마, 겁살, 망신으로 반증할 기회조차 없었다.
타 서비스의 출력은 12.1 이 말하는 채택 근거가 아니다.
천문성과 귀문관살을 미채택한 것과 같은 기준을 여기에도 적용한다.

재검토 조건은 월지나 시지 기준을 지지하는 문헌 근거를 확보한 경우에 한한다.
타 서비스와의 출력 차이는 재검토 사유가 아니다.

### 12.9 미채택 목록

C 등급이라 채택하지 않은 것: 천문성, 귀문관살, 황은대사, 급각살, 단교관살.

A·B 등급이지만 아직 미구현이라 추가 후보인 것: 천덕귀인, 월덕귀인(월지 기준, 삼명통회 계열).
