# ADR 0007. 신강약은 5단계 4요소 모델을 쓴다

- 상태: 채택(Accepted)
- 날짜: 2026-08-05

## 배경

[ADR 0006](0006-manseryeok-and-time-correction.md) 에서 승계하기로 한
`/Users/mychoi/f-lab/saju` 의 도메인 문서 두 개가 신강약 정량화를 서로 다르게 정의하고 있었다.
둘 다 구현 위치로 같은 파일(`strength.ts`)을 지목한다.

| 출처 | 모델 | 산출 방식 |
|------|------|-----------|
| `saju-domain-rules.md` §11 | 8단계 | 지장간 가중치로 세력을 계산해 방조 비율 백분율을 내고 구간을 나눈다 |
| `strength-grading-spec.md` | 5단계 | 득령·득지·득시·득세 네 불리언을 가중 합산한다 |

신강약은 업계 표준이 없는 정량화 모델이라 어느 쪽도 틀렸다고 할 수 없다.
다만 두 모델이 공존한 채로 옮기면 같은 충돌이 그대로 재발한다.

## 결정

5단계 4요소 모델을 채택한다.

1. 판정 요소는 득령(월지 본기), 득지(일지 본기), 득시(시지 본기), 득세(일간 제외 7글자 중 지원 4개 이상) 네 개다.
   지원 세력은 비겁과 인성이다.
2. 등급은 태강, 신강, 중화, 신약, 태약 다섯이다.
   네 요소가 모두 참이면 태강, 모두 거짓이고 지원 글자가 1개 이하면 태약이다.
   그 외에는 `score = 득령×2.0 + 득지×1.0 + 득시×0.5 + 득세×1.5` 로 계산해
   3.0 이상은 신강, 1.5 이상 3.0 미만은 중화, 1.5 미만은 신약이다.
3. 용신 분기는 태강이면 식상(설기), 신강이면 관성(극제), 신약과 태약이면 인성(생조)이다.
   중화는 억부가 불필요하므로 `needsJohuReview` 플래그를 올려 조후나 병약 등 다른 용신법 검토로 넘긴다.
4. 가중치와 임계값은 전부 설정 상수로 노출한다.
   verified 검증 케이스가 늘어나면 재보정하되, 월령 가중이 가장 크다는 원칙은 유지한다.

`saju-domain-rules.md` §11 의 8단계 모델은 승계 시 본문에서 제거하고 기각 기록으로만 남긴다.

## 이유

- 검증 케이스 13개가 5단계 모델 기준으로 작성되어 있다.
  승계하는 즉시 회귀 테스트가 성립하고, 기준 케이스(1995-01-27 14:39 여, 서울)의 태강 판정과
  용신 금이 그대로 재현된다. 8단계를 택하면 케이스를 전부 다시 만들어야 한다.
- 득령·득지·득시·득세는 명리 전통 용어 그대로다. 화면에 근거를 보여줄 때 설명이 필요 없다.
- 판정 요소가 네 개뿐이라 결과를 손으로 검산할 수 있다.
  8단계 모델은 지장간 가중 합산이라 어긋났을 때 어디가 문제인지 짚기 어렵다.

## 트레이드오프 / 대안

- 불리언 네 개가 기반이라 8단계 모델보다 해상도가 낮다.
  경계 근처에서 등급이 튀고, 세력이 조금씩 다른 사주가 같은 등급으로 묶인다.
- 8단계 모델이 갖고 있던 종왕격 순세, 관성 세력 10퍼센트 조건 같은 세밀한 분기를 잃는다.
  전왕격과 종격은 플래그(`considerJeonWangGyeok`, `considerJongGyeok`)로만 남기고 판정은 하지 않는다.
- 해상도가 문제가 되는 것이 확인되면 8단계 모델로 이행할 수 있다.
  그때는 이 ADR 을 대체하는 새 ADR 을 쓰고 검증 케이스를 다시 만든다.

## 영향

- [`docs/05-saju-domain-rules.md`](../05-saju-domain-rules.md) 에는 신강약 모델이 하나만 존재한다.
  두 모델이 공존하면 승계 실패로 본다.
- 신강약 판정 결과가 용신 분기의 입력이고, 그 둘이 LLM 프롬프트의 핵심 입력이다
  ([ADR 0005](0005-rule-engine-plus-llm-interpretation.md)).
- 임계값을 바꾸면 판정이 바뀌고 해석 캐시 키도 바뀐다.
  상수 변경은 검증 케이스 재실행을 동반한다.
